# STRUMYK SPORTS × Lampa

Дослідницький проєкт плагіна під https://strumyk.ca/ для LampaS та Lampa Uncensored.

## Статус — v0.4.0 research

Встановлено на трьох реальних браузерних знімках (21–22.11.2026):
- #schedList містить 188 подій .sched-item з унікальними data-id, 29 позначені LIVE.
- .tile[data-id] дають назви ліг; в обрізаному дампі 126 таких карток.
- Матч #QweLd3hK має #sources із джерелами 7 мовних груп; наявність багатьох варіантів HD/FHD підтверджено, але адреси й методи програвання не підтверджені.
- Скрипти сайту: /js/strumyk-schedule.js, /js/strumyk-app.js; в мережевому логу /api/L.php, J.php, X.php, M.php, O.php. Їхню семантику поки не перевірено.
- Локальний JS-парсер v0.4 читає фактичну структуру розкладу; тест на вибірці користувача: 188/29, PASS.
- Попередній DOM-дамп обрізався до блоку #sources. Додано нову вибіркову діагностику джерел [tools/strumyk_capture_sources_v04.js](tools/strumyk_capture_sources_v04.js).

**Увага:** реальний live API та відтворення на Lampa/Android ще не перевірені. Не трактуйте дослідницький прототип як готовий реліз.

Базові вимоги: гарний UI телефон/TV (фони окремо), UA за замовчуванням + PL/RU словниками, оригінальні назви команд, фільтри, всі джерела для кожної події, програмний Lampa-плеєр та зовнішні VLC/MX. Після з'ясування API перевіряти все на обох збірках Lampa.

Публічний GitHub не призначений для дампів із приватними посиланнями/ключами. LiveTV-плагін окремий та незмінений.

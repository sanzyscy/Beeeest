# STRUMYK SPORTS v0.29 — повний аудит інтерфейсу та виправлення накладань

**Дата:** 22.11.2026. **Основа:** окрема копія `v0.28`. Попередні файли НЕ змінені. Це UI/навігаційне виправлення, **не** підтверджений реліз роботи DRM-відео.

## Що було на реальному скріншоті
На вертикальному смартфоні (691×1536 px у наданому скріншоті) тестовий блок DASH займав майже весь екран; заголовок частково опинився вище видимої ділянки, Start/Stop/error повідомлення були під ним, а **плаваюча нижня панель Lampa** накладалася на інтерфейс. Раніше було аналогічне накладання в картках матчів та TV.

## Конкретні причини в коді v0.28

- `.str-video-shell{height:56vh;min-height:180px}` робив надмірно високий плеєр у портретній орієнтації.
- `.str-screen{height:100%;overflow:hidden}` і `.str-area{flex:1;overflow-y:auto}` не резервували площу поза плагіном для нижньої навігації Lampa.
- `draw()` повторно заповнював `.str-area`, але не скидав `scrollTop` при переході між логічними екранами. Новий екран іноді відкривався з обрізаним заголовком.
- У `drmDemoView()` було: пояснення → статус → **велике відео** → Start/Stop/Close. Помилка була над відео, але після прокручування та зміни екранів стала неочевидною й часто недоступною.
- У `drmView()` кнопки тестів були **після** довгого `pre` звіту.
- `L.Input.edit()` залишався у редакторі адреси сервера та невикористаному ручному TV-редакторі. Такий системний діалог раніше блокував пошук на смартфоні.
- `L.Noty.show()` міг показувати повідомлення знизу, під системною панеллю.
- При перемальовуванні активного DRM-демо через інші асинхронні події видалявся елемент `<video>`, залишаючи програвач прив'язаним до неіснуючого DOM.
- Перехід між вкладками під час активного демо не закривав ізольований плеєр.

## Що реалізовано

1. **Спільні безпечні відступи.** Функція `syncUiInsets()` намагається визначити накладену нижню навігацію за її DOM-прямокутником, резервує простір через `--str-bottom-safe`. Для вузького вертикального сенсорного екрана є консервативний fallback **84 CSS px** (не фізичних пікселів). Не приховує й не змінює власну нижню панель Lampa.
2. **Гарантовано прокручуваний контент:** `min-height:0`, `flex:1 1 0`, `overflow-y:auto`, `overscroll-behavior:contain`, `scroll-padding`; нижній футер та керування залишаються над зарезервованою ділянкою.
3. **Скидання scrollTop лише при переході на інший екран:** збереження прокручування всередині тієї самої картки чи списку.
4. **Відеоблок 16:9**, обмеження висоти відносно viewport, медіаконтент `object-fit:contain`. Для DRM-демо нижня межа `min-height:0` і менший `max-height`.
5. **DRM-демо:** заголовок → Back → пояснення → **липкий статус з кодом помилки** → **Start / Stop / Close** → компактне відео. Статуси `PLAYBACK_OK`, `ERROR`, `TIMEOUT` мають різні стилі, без величезного модального повідомлення.
6. **DRM-діагностика:** кнопки ClearKey/HTTP/тест відео/Close перенесені перед `pre`; `pre` має окремий обмежений скрол.
7. **Host URL:** замість системного `L.Input.edit()` власне поле із Save / Cancel, перевіркою адреси, Back/Escape/Enter. Невикористаний старий редактор TV-потоку вилучений; збережені раніше налаштування потоків не видалено.
8. **Усі повідомлення від плагіна** перенесені до тимчасової панелі зверху в межах STRUMYK, з кнопкою «✕».
9. **Навігація/життєвий цикл:** переходи між вкладками й налаштуваннями звільняють демонстраційний DASH-плеєр. Повторний `draw()` активного демонстраційного екрана не від'єднує `<video>` від плеєра.
10. **CSS ізольований:** окрема таблиця стилів `#strumyk-layout-v029` перевизначає тільки `.str-...`; штатний UI Lampa й сторонні плагіни не приховуються.

## Перевірка за екранами

| Екран / функція | Перевірені зміни |
|---|---|
| Розклад / «Наживо» / Обране | Спільна прокрутка, відступ над нижньою панеллю, текст карток, переходи між вкладками |
| Картка спортивної події | Доступність кнопок, WEB/HLS повідомлень, списку джерел, прокрутка |
| Пошук спорту й телеканалів | Збережено inline-поле з Cancel, без системного `L.Input.edit` |
| Телебачення / EPG 56 каналів | Спільний адаптивний контейнер, скрол, нижні TV-кнопки |
| WEB-плеєр | Адаптивна рамка 16:9, Back / Browser / Refresh зверху |
| DRM capability / мережа | Кнопки керування перед великим звітом |
| ClearKey demo | Статус і код зверху, запуск перед відео, пропорційний плеєр, очищення ресурсів |
| Зміна адреси сайту | Власний редактор із Save/Cancel |
| Повідомлення | Власна тимчасова панель угорі, незалежна від панелі Lampa |

## Тести, виконані до перевірки на пристрої

- Повний синтаксис JS: **PASS**.
- Відновлення незалежного stylesheet та баланс фігурних дужок CSS: **PASS**.
- Viewport-функція на макетах: `390×850 touch → 84 px`, `390×850 з видимою нижньою панеллю → 128 px`, `1920×1080 non-touch → 0 px`: **PASS**.
- Перенесення статусу і Start/Stop над відео та фокусні Back/Cancel: **PASS у коді**, реальне відображення потрібно перевірити.
- JSON-парсер спортивної події й одного джерела, канонічний `/#id`: **PASS**.
- 56 TV каналів і EPG `Зараз/Далі` на тестових кортежах: **PASS**.
- Немає `L.Input.edit` у коді v0.29, викликів `Termux Bridge`, `resolveViaBridge`: **PASS**.
- Справжнє ClearKey-демо, доступ до CDN, конкретне відео в Android Lampa після зміни UI: **ще не протестовані**.

## Установка

`https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@3c4a4f6ead7784ba6fb3f62275f21c3b5ea2cc28/test/strumyk_plugin_v029_ui_layout_fix_test.js`

Вказана pinned URL відповідає кандидату до останнього оновлення перевірок: **перед фінальним використанням перевірити поточний SHA-commit**; для стабільної адреси дозволено використовувати `https://raw.githubusercontent.com/sanzyscy/Beeeest/main/test/strumyk_plugin_v029_ui_layout_fix_test.js` із ризиком кешу. Виробничим релізом не називати.

1. Вимкнути v0.28, закрити Lampa повністю, встановити v0.29 (тільки один STRUMYK).
2. Залишити Android Lampa на HTTPS URL `https://bylampa.online/`.
3. Відкрити `⚙ → DASH / DRM → ▶ Демовідео ClearKey DASH`.
4. Перевірити: заголовок, статус, Start/Stop **над** відео; останні кнопки доступні без накладання нижньої панелі; назад повертає до DRM.
5. Натиснути Start. Повідомлення помилки повинно бути **над відео**. Зафіксувати код і чи змінюється `0:00`.
6. Додатково перевірити скрол на кінці списку телеканалів та картки матчу, а також пошук і зміну URL у налаштуваннях.

**Не робити висновку, що потоки Strumyk уже запустилися у VLC/MX чи Lampa Player.** Поки ми виправили лише клієнтський UI. Сам DASH із EME/DRM потребує дозволеного доступу та правильного налаштування.

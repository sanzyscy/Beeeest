# STRUMYK SPORTS — підтвердження DASH/Shaka у працюючому браузері (22.11.2026)

## Джерело
Отримано від власника тестовий, локально знятий `STRUMYK_SPORT_PLAYER_V024_2026-11-22T04-02-19-141Z.json`. Метадані очищені від значень токенів, signed URL і секретів. **Ці URL та секрети не копіювати до репозиторію.**

## Підтверджено зі знімка
- Подія: **Vancouver Canucks — Minnesota Wild**.
- Активний варіант якості: **Ultra HD**; `selectedSource` і `frameSource` **точно збігаються**.
- WEB-плеєр: **`https://strumyk.ca/e/vip/UK/premiersports1.php`**. Це same-origin iframe з `referrerPolicy=no-referrer-when-downgrade` і **без sandbox**. Попередньо згадувався шлях **`/e/vip/PL/...`**, але знімок не доводить, який саме URL повертав 404 у Lampa, бо попередній скріншот не показав повного URL.
- Вкладений HTML використовує **Shaka Player 4.15.5** (`shaka-player.ui.min.js`).
- Медіаманіфест **MPEG-DASH**, URL з CDN **`a122aivottlinear-a.akamaihd.net`**, шлях містить `/dash/enc/` і закінчується `/cenc.mpd`, **HTTP 200**.
- Перший ресурсний знімок: **57 ресурсів** (1 DASH-маніфест, 54 MP4 fragments, 2 Shaka assets); серед них **54 з HTTP 200**, інші без доступного статусу у Resource Timing.
- `video` всередині iframe: **blob:**, `readyState=4`, `1920×1080`, спершу `paused=false`. Другий знімок через 4,66 с: `paused=true`, без нового маніфесту в поточному ресурсному зрізі.

## Висновки та чіткі межі
1. Тут використовують **DASH**, а не HLS. Назва `cenc.mpd` і шлях `/enc/` створюють **сильну підозру на Common Encryption / DRM**, але жоден з цих рядків не доводить, чи саме використовується EME, Widevine, PlayReady, ClearKey і чи є легітимна DRM-ліцензія.
2. Факт HTTP 200 для `.mpd` та `.mp4` **не доводить**, що незахищений VLC/MX Player зможе відтворити фрагменти. Для DRM потрібна підтримувана платформа й дозволена ліцензія.
3. Локальне `blob:` у HTMLVideoElement — **не пряма адреса** для зовнішнього відеоплеєра.
4. При порівнянні зі старим джерелом `/PL/` **перевіряти точну адресу кожного конкретного матчу**: у цьому працюючому прикладі `/UK/`, не `/PL/`.
5. Гарантоване відтворення у зовнішньому VLC/MX **НЕ доведено**, не рекламувати його й не випускати «виправлену відеоверсію» на підставі одного ресурсного логування.

## Наступна діагностика без обхідних дій
- Файл `tools/strumyk_sport_drm_capabilities_v025.js`: одноразовий, read-only запуск у вже відкритій сторінці матчу. Перевіряє `video.mediaKeys` та в разі доступу глобального екземпляра `shaka.Player.getDrmInfo()`, індикатори `license / DRM / cenc`, лише типи мережевих ресурсів. **Не читає DRM-ключів, токенів, адрес ліцензій, ContentProtection payload чи PSSH**, не завантажує маніфест, не проводить авторизацію.
- Коли `EME MediaKeys` або `getDrmInfo()` підтверджуються, для Lampa Player (Android) законний шлях — підтримуваний DRM API й правомірна ліцензія, не перепризначення URL у VLC.
- Якщо EME не виявлено, висновок поки **«DRM не підтверджено»**, а не **«потік відкритий»**: тоді окремо перевіряти доступність актуального MPD без секретів у незалежному клієнті.

# STRUMYK SPORTS v0.35 — WEB iframe compatibility (HTTP Lampa)

**Дата:** 2026-11-22  
**Статус:** експериментальна версія, на пристрої ще НЕ тестувалась.  
**База:** перевірена користувачем за скріншотами v0.34 `test/strumyk_plugin_v034_autostream.js` (commit `88876573223794b952d41e4b70297e4216771638`).

## Встановлення

https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@d9d4a1cb236785e3c1a5bb0724cb0ec7693142dc/test/strumyk_plugin_v035_web_iframe_compat_test.js

Вимкнути v0.34, повністю перезапустити Lampa Uncensored через **HTTP**, установити лише v0.35. Плагіни двох версій одночасно не активувати (у них спільна реєстрація).

## Які помилки взято зі скріншотів

1. `This player does not play inside a sandboxed iframe. Site owner: remove the sandbox attribute from the iframe.` — **виправлення в нашому WEB iframe можливе**. `v0.34` додавала `sandbox`, хоча оригінальний Strumyk створює iframe без цього атрибута.
2. `Access Denied: Embedding is only allowed on authorized domains.` — це **обмеження власника стороннього плеєра**, а не дефект `sandbox`. Зняття `sandbox` не робить Lampa авторизованим доменом. Якщо провайдер блокує стороннє вбудовування, працюючий варіант — відкрити офіційну сторінку Strumyk у браузері; не підмінюємо Origin/Referer/авторизацію.
3. Окремі iframe уже показували кадри відео на v0.34; їхню поведінку не слід погіршувати через нові перевірки або перехоплення мережі.

## Зміни (строго ізольовані)

- Єдині зміни в JS порівняно з v0.34 — рядок `VERSION` та функція `webPlayer()`.
- Для **публічних зовнішніх HTTPS WEB-джерел** створюється звичайний iframe **без атрибута `sandbox`** за замовчуванням, як на сайті Strumyk. Це усуває конкретну причину відмови `sandboxed iframe` (якщо інших обмежень немає).
- `referrerpolicy` змінено з `strict-origin-when-cross-origin` на `no-referrer-when-downgrade`, як в оригінальному коді Strumyk. Важливо: реальний HTTP Origin Lampa не змінюється.
- З'явилася локальна перемикач-кнопка `🛡 Увімкнути sandbox` / `▶ Без sandbox (сумісність)` для порівняння результату. Зміна режиму перевідкриває поточний iframe; на новому джерелі знову обирається сумісний режим. Для HTTP або same-origin iframe збережено `sandbox`.
- Для `Access Denied` є чесне пояснення та вже наявна кнопка `↗ Браузер` у верхньому рядку.
- URL проходить існуючу `safeUrl`; небезпечні/некоректні URL не завантажуються.
- Кнопки `Попереднє`, `Наступне`, `Усі джерела`, `Назад` і поточний адаптивний UI залишені.

## ЩО НЕ ЗМІНЕНО

**Повністю побайтно незмінні**: `openStream`, `chooseSource`, `chooseWebPlayback`, HLS/AutoStream із v0.34, XOR-декодер, `Lampa.Player.play`, нативні запити, HLS `pLoader/fLoader`, каталог, EPG, статуси LIVE, Android Back, LiveTV плагін.

**Примітка:** ця версія не виправляє раніше знайдені ризики глобального HLS-патча v0.34, оскільки задача — тільки WEB iframe, без втручання в успішне Lampa-відтворення.

## Результати перевірок перед публікацією

- Парсинг JavaScript V8: **PASS**.
- Порівняння префіксу й суфіксу з v0.34: **PASS, побайтно однакові** (окрім версії та WEB-функції).
- 15 ізольованих перевірок WEB-розмітки/керування: **PASS** (HTTPS без sandbox, режим sandbox ON/OFF, referrerpolicy, кнопки, HTTP/same-origin захист, перемикання джерела, заборонена схема URL).
- **Реальне відтворення в Android WebView і Lampa Player після встановлення v0.35 ще не перевірено.**

## Послідовність реального тесту (важливо)

1. **Спершу перевір незмінений Lampa Player**, використовуючи той самий раніше працюючий відеопотік із v0.34. Переконайся, що є звук, рух кадрів, `1920×1080`, буфер і що відео працює кілька хвилин. Якщо зламалось — відразу відкотись до v0.34 й повідом, яку помилку видає плеєр.
2. Відкрий у STRUMYK ту саму картку з 9 WEB-джерелами. Перевір **4/9**, де була помилка `sandboxed iframe`. Повідомлення про sandbox тепер має зникнути; це ще не гарантія роботи відео.
3. Перевір **5/9** із раніше видимим відео Arena Sport 2, потім перемкни на 6/9 та 8/9. Для `Access Denied` автоматичного виправлення не обіцяємо.
4. На джерелі, що відмовляється працювати, порівняй звичайний режим та `🛡 Увімкнути sandbox` і повтори тест. При переключенні режиму iframe перезавантажується.
5. Перевір Back, переходи між WEB-джерелами й повернення до картки події. `↗ Браузер` повинен відкривати сторінку матчу на самому Strumyk.

## Межі сумісності та безпеки

Режим без `sandbox` дозволяє сторонній сторінці працювати зі звичайними браузерними можливостями iframe. Це підвищує сумісність із її плеєром, але зменшує ізоляцію. Використовуй тільки джерела, яким довіряєш; захищений режим можна повернути кнопкою. Відсутність `sandbox` не вимикає перевірки CSP `frame-ancestors`, X-Frame-Options, сторонніх доменів чи DRM.

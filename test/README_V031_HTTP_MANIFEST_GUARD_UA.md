# STRUMYK SPORTS v0.31 — HTTP / безпечна перевірка медіаманіфестів

**Дата:** 22.11.2026  
**Статус:** нова ТЕСТОВА версія, на Android Lampa користувачем ще не перевірена.  
**Основний режим Lampa:** HTTP (за останнім рішенням користувача).

## Файли та встановлення
- JS: `test/strumyk_plugin_v031_http_manifest_guard_test.js`
- Піноване посилання: https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@a7358fc6a539f6be12f9ddd80d8cba668f0a7bcd/test/strumyk_plugin_v031_http_manifest_guard_test.js
- Відкат до перевіреної v0.30: https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@530d0360638175c314f7835f3d9a39a5a8453607/test/strumyk_plugin_v030_back_controller_fix_test.js

**ВАЖЛИВО:** HTTP стосується самої сторінки Lampa (`location.protocol=http:`). Адреса вихідного сайту Strumyk залишається **HTTPS** (`https://strumyk.ca/`); її не треба переводити на HTTP.

Перед тестом вимкнути v0.30, повністю закрити Lampa і запустити знову; одночасно дві версії не встановлювати (є спільний прапорець ініціалізації).

## Зміни від v0.30
1. Новий чистий аналізатор `inspectMediaManifest(raw,type)`, повертає `valid,type,protection,note`. Має категорії `clear` (без видимих ознак у перевіреному маніфесті), `unknown` (HLS master без аналізу вкладених списків), `aes128` (типовий HLS AES-128, **не прирівнюємо автоматично до DRM**), `protected` (DASH `ContentProtection`, HLS SAMPLE-AES / сторонній KEYFORMAT).
2. Звичайний IPTV M3U з `#EXTM3U` та `#EXTINF`, але без тегів `#EXT-X-...`, **не проходить як HLS**.
3. Автоматичний пошук, вибір прямого HLS/DASH у картці та перехід від WEB-джерела до знайденого маніфесту мають додаткову read-only перевірку перед запуском. `protected` блокується **для цього HTTP-режиму** з поясненням, без обходу DRM.
4. Для `aes128` та `unknown` пропонується тест у плеєрі з явним попередженням, що ключовий URI/вкладені списки й сумісність ще не перевірені.
5. У HTTP-контексті не показується кнопка недоступного EME ClearKey демо, але залишається загальна діагностика можливостей.
6. У загальній діагностиці з'явилися `Lampa protocol` і `Secure context`.

**Не змінено:** каталог J/O/M/X/L, EPG, UI v0.30, Back-controller fix, окремий LiveTV, еталонні v0.14/v0.19/v0.29/v0.30, налаштування Strumyk URL.

## Як перевірити на смартфоні (без ПК)
1. Встановити **лише v0.31** за посиланням вище; Lampa має бути запущена через HTTP.
2. STRUMYK → ⚙ → **Діагностика**: знайти `Lampa protocol: http:` і записати, скільки реально завантажилось спортивних подій.
3. Відкрити TV: перевірити кількість каналів і блоки EPG `Зараз / Далі`. Старі **189 подій та 56/56 EPG — це результат попереднього тесту, не гарантія поточної кількості.**
4. Відкрити матч із джерелами → `▶ Перевірити прямий HLS/DASH`. Записати **дослівно** результат у рядку статусу.
5. Якщо знайдено маніфест, окремо перевірити `Lampa Player`, а за бажанням `VLC / MX Player`. Записати: чи видно кадри, чи є звук, тривалість стабільного відтворення. **Успішна відповідь маніфесту не доводить роботу сегментів.**
6. Відкрити конкретне джерело `WEB`, спробувати окремо WEB iframe та режим пошуку HLS/DASH. Звернути увагу, якщо сервер повернув 403/404, або якщо маніфест захищено.
7. Перевірити кнопку `‹ Назад` усередині STRUMYK і системний Android Back, особливо після спроби програвання.

Для звіту достатньо скріншотів результатів та назви події. **Не надсилати токени, ключі, cookies, підписані посилання.**

## Межі достовірності
- Статичну компіляцію JS перевірено у V8; **9 синтетичних зразків**: HLS відкритий, HLS master, HLS AES-128, HLS SAMPLE-AES, HLS SESSION-KEY, IPTV M3U-not-HLS, DASH ContentProtection, відкритий DASH, HTML-not-DASH. Також перевірена класифікація URL HLS/DASH.
- **Виконання у реальній Android Lampa, Android TV, фактичні мережеві відповіді та звук/кадри у v0.31 не тестувалися.**
- MPD із `ContentProtection` позначається консервативно: цей тег не розкриває сам собою спосіб отримання права на відтворення. HLS master без `EXT-X-KEY` на верхньому рівні **не вважається гарантовано відкритим**.
- `Referer`/`User-Agent` у браузерних, нативних і зовнішніх програвачах не гарантовано передаються однаково.
- Повний обхід CORS, отримання DRM-ключів, перехоплення сесій та приховані посередники відсутні.

## Наступне рішення після тесту
Якщо каталог, TV EPG і Back не зламалися, вибрати одну конкретну спортивну подію з перевіреним **незахищеним** HLS/DASH та виміряти реальне відтворення в Lampa, VLC, MX. Якщо таких джерел немає — звітувати про відсутність, не вигадувати потоки.

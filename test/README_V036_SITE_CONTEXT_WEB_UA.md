# STRUMYK SPORTS v0.36 — тест WEB через офіційну сторінку Strumyk

Дата: 22.11.2026. **Тестовий файл, не перевірений на Android.**

## Встановлення
https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@99b9047a403349bd002afa232022e8dc05e5fc8f/test/strumyk_plugin_v036_site_context_web_test.js

Перед встановленням вимкнути v0.35, повністю перезапустити Lampa й увімкнути лише v0.36. Основна сторінка Lampa працює через **HTTP**, сайт Strumyk — через HTTPS.

## Проблема зі скріншота
WEB iframe в v0.35 після відключення `sandbox` усе одно показує:

```
Access Denied
Embedding is only allowed on authorized domains.
```

Це схоже на перевірку дозволеного домену у стороннього провайдера. В Lampa **неможливо** зі звичайного JS встановити довільний `Referer: https://strumyk.ca/` для iframe. `referrerpolicy` керує передаванням фактичного referrer, а не підміняє його.

## Що зроблено (лише WEB)
- Версія `0.36.0-site-context-web-test`.
- У WEB-екрані події з коректним ID з'явилася кнопка **«🌐 Через сторінку Strumyk»**.
- За замовчуванням лишається перевірена схема v0.35: **прямий WEB iframe провайдера**, без sandbox для зовнішніх HTTPS-джерел.
- За натисканням нової кнопки замість провайдерного `embed` відкривається **офіційна сторінка Strumyk** `https://strumyk.ca/#<ID>` всередині того самого WEB-вікна. Якщо сторінка справді відкриється, вона вже самостійно створює вкладений iframe провайдера.
- Кнопка перемикається на **«↩ Пряме WEB-джерело»**. Це скидає експеримент і повертає попереднє провайдерне посилання.
- Кнопка «Наступне ▶» / «Попереднє» повертає прямий WEB-режим і вибирає нове джерело.
- У режимі сторінки Strumyk WEB-рамка збільшена у висоту до 68vh, бо це повна сторінка, а не лише відео.
- Кнопка `🛡 Увімкнути sandbox` та зворотне перемикання працюють як у v0.35.

**Важливо:** це **не підробка Referer/Origin**. Навіть така вкладена офіційна сторінка може не працювати у iframe через CSP `frame-ancestors`, `X-Frame-Options` чи перевірку ланцюга вкладених рамок. Сайт може автоматично обрати інший потік, не той, що був у прямому WEB режимі.

## Недоторканні частини
Порівняння із `test/strumyk_plugin_v035_web_iframe_compat_test.js`: **побайтно незмінні всі частини JS поза функцією `webPlayer()` та рядком `VERSION`**.

Зокрема не змінювалися `Lampa.Player.play`, `openStream`, `chooseSource`, `chooseWebPlayback`, `resolveOpenMedia`, `findDirectMedia` з XOR, HLS/AutoStream-патч, `pLoader`, `fLoader`, рендер каталогу, EPG, LIVE, Back та інший LiveTV. Оригінальні v0.34 і v0.35 не переписувалися.

## Перевірено до встановлення
- Синтаксис JS: **PASS**.
- Суворе порівняння байтів поза WEB-плеєром: **PASS**.
- 18 ізольованих тестів WEB: **PASS**. Перевірено звичайний режим; кнопки та URI; перехід на `https://strumyk.ca/#ID`; повернення; перемикання джерел; безпечні ID; sandbox і referrerpolicy.
- Реальні CSP/iframe/WebView/HTTP результати та фактичне відео: **ще не перевірено**.

## Порядок тесту на смартфоні
1. Перевір відтворення в **штатному Lampa Player**, яке працювало у v0.34 (1920×1080, рух, звук, буфер). Якщо зламалось — відкотитися до v0.34 і повідомити.
2. Відкрий ту саму подію з 9 WEB-джерелами, вибери **6/9**, де є «Access Denied».
3. У WEB-екрані натисни **«🌐 Через сторінку Strumyk»**. Перевір, чи відобразилася офіційна сторінка, чи з'явився плеєр і чи є рух/звук.
4. Натисни **«↩ Пряме WEB-джерело»**, переконайся, що повернулося 6/9. Для порівняння спробуй 4/9 (раніше sandbox), 5/9 (раніше кадри) та 8/9.
5. Якщо офіційна сторінка всередині iframe заблокована — натисни звичайну **«Браузер»**. Це очікуваний запасний шлях.
6. Надішли скріншоти та короткий опис того, що саме відкривається. Не надсилати cookies, токени чи ключі.

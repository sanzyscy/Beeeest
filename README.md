# STRUMYK SPORTS × Lampa

Дослідницький проєкт плагіна для **LampaS / Lampa Uncensored** під сайт https://strumyk.ca/.

## Статус — 0.1.0 (research)

Підготовлено локальний прототип інтерфейсу: українська за замовчуванням, польська й російська, фільтри спорту/ліги/дати/статусу, обране, багатоджерельний список, класифікація HLS/DASH/YouTube/AceStream та передавання сумісних прямих посилань у Lampa Player.

**API та реальне відтворення Strumyk ще не перевірені.** Під час зовнішньої перевірки головний сайт відповідав HTTP 403. Через це поки НЕ публікуємо неперевірену JS-збірку як нібито робочий реліз.

## Звідки беруться дані

Тільки з підтвердженого `strumyk.ca` або вказаного сумісного дзеркала після технічної перевірки. Сторонні `strumyknet.pl`, `strumyktv.com.pl` не підмішуються. ID події можуть мати формат `/#p0aFxkkn`.

## Наступний крок

Отримати з Android/Termux анонімний технічний звіт про HTML/JS/API сайту; прив'язати парсер до фактичної схеми та перевірити запуск на телефоні й TV.

Власник: Lastimpact_ua. Робочий LiveTV-плагін не змінюється.

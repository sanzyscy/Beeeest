# STRUMYK SPORTS × Lampa

Дослідницький проєкт для LampaS та Lampa Uncensored, основна адреса: https://strumyk.ca/.

## Стан — v0.6 research (22.11.2026)

Опрацьовано сім знімків публічних JS (чотири з головного спортивного розділу, три з `/telewizja/`). Усі містили ті самі два файли: `/js/strumyk-app.js` та `/js/strumyk-schedule.js`, тому ТВ-каталог з них **не отримано**.

**Спортивна схема підтверджена кодом сайту:** `window.SK.api.L/J/X/M/O`; паралельне отримання JSON-масивів; дедуплікація за `id` з пріоритетом J→O→M→X→L; `J` — популярні. Подія має `title.pl.home/away`, `startTime`, `category`, `tournament`, `_embeds`; embed-масиви розподіляються за `language` і містять `label`, `embed`.

У локальному прототипі v0.6 реалізовано чистий API-парсер `parseStrumykApiBundle` із підтвердженою схемою, правильне розділення веб-iframe і прямих медіапотоків, тести JSON + збережених DOM-знімків. **Живі API-виклики, запуск Lampa, VLC/MX та ТВ-каталог не перевірені.** Плагін ще НЕ публікується як реліз.

### Телеекрани

Код сайту `/js/strumyk-schedule.js` автономно працює на TV сторінці через `window.SK_SCHED`, але це стосується спортивного розкладу й не доводить джерело ТВ-каналів.

**Наступний крок:** запустити з `/telewizja/` нашу [цільову TV-діагностику v0.6](tools/strumyk_tv_capture_v06.js), спершу на каталозі, потім з відкритим каналом. Експортує лише локальний JSON з очищеними URL, DOM-метаданими, скриптами й назвами API-параметрів.

## TV-дослідження v0.7 (22.11.2026)

Шість браузерних знімків `/telewizja/` підтвердили: **56 каналів**; фільтри `podstawowe=11`, `sport=28`, `news=3`, `film=8`, `rozrywka=6`. На сторінці є `window.CHANNELS` (масив об'єктів) та виклик `/api/epg.php`. Відкриті сторінки Polsat Sport Premium 2, Eleven Sports 4 та Polsat Sport Extra 3, але прямі відеопотоки ще не доведені.

Від власника є вимога **не витрачати релізний час на повну семиденну EPG-сітку**. Для TV варто зробити пошук, категорії, обране, доступні джерела; за потреби пізніше — компактний «Зараз / Далі» з прогресом.

Нова [безпечна TV-діагностика v0.7](tools/strumyk_tv_channels_v07.js) вивантажує об'єкти `window.CHANNELS` у локальний JSON з маскуванням query/секретоподібних полів. Попередні v0.6-знімки цього не робили.

Дзеркала зі скріншота `rentry.co/strumyk`: `strumyk.ca`, `strumyk.cv`. Наявність у переліку **не гарантує доступність** — попередня TLS-перевірка `.cv` була невдалою.

JS-плагін v0.6 все ще є дослідницьким прототипом, live інтеграцію в Lampa не підтверджено.


## Компактна телепрограма: v0.8 research (22.11.2026)

- З реального знімка TV \`window.CHANNELS\` отримано **56 каналів**, \`id,name,logo,cat,url\`: 11 основних, 28 спортивних, 3 новинних, 8 фільмових, 6 розважальних.
- 51 запис має порожній URL, один із п'яти заповнених URL містить замасковані параметри. Дані каталогу **не є доказом працездатності відтворення**.
- На сторінці фактично спостерігали \`/api/epg.php\`, але реальний JSON-формат (і часовий пояс) іще невідомий.
- Локально підготовлено офлайн-модуль \`tv/strumyk_tv_epg_core.js\` (поки тільки в дослідницькому ZIP): «Зараз», «Далі» і % прогресу; час без відомого часового поясу навмисно не вгадує. Локальні тести: PASS.
- [tools/strumyk_epg_capture_v08.js](tools/strumyk_epg_capture_v08.js) — одноразовий браузерний GET **лише /api/epg.php** без cookies; зберігає локальний очищений JSON-фрагмент структури, не повний телегід.
- Повну EPG-сітку на сім днів **не плануємо**. Компактний індикатор необов'язковий і не повинен заважати відео. **Живий EPG у Lampa ще не підключений; релізу немає.**

## EPG-дослідження v0.9 (22.11.2026)

Останній реальний браузерний знімок /api/epg.php підтвердив HTTP 200, application/json, 111853 символи, 311 мс, root keys: ok,date,today,from,to,now,pending,ch,logo. Поле ch містить 56 каналів з id,e,fb,it; у першого каналу it містить 44 записи, **кожен — масив із 4 значень**. v0.8-діагностика помилково шукала об'єкти-передачі, тому не зберегла жодного прикладу і не може довести порядок колонок чи часовий пояс.

Додано [tools/strumyk_epg_tuples_v09.js](tools/strumyk_epg_tuples_v09.js): один read-only GET /api/epg.php з Chrome, локальний JSON лише з обмеженою вибіркою чотирикомпонентних рядків та кореневими часовими полями. Після його результату зможемо встановити точне відображення: канал → поточна передача → наступна → % прогресу.

Не заявляти, що EPG вже працює в Lampa: основний JS-плагін усе ще дослідницький прототип v0.6. Повна 7-денна EPG-сітка не планується.

## Проміжний результат v0.10 (22.11.2026)

Користувач надав реальний `STRUMYK_EPG_TUPLES_V09`. Доведено точний формат EPG: `/api/epg.php` → `{ok:1,now,ch:[{id,e,fb,it:[[startUnixSec,endUnixSec,title,genre],...]}]}`. Зіставляти за `ch.id`, не `ch.e`. 56/56 ID збігаються зі списком телеканалів.

Локальний кандидат `strumyk_plugin.js v0.10.0-research` (поки **не завантажений у репо**) тепер містить TV-вкладку: 56 зафіксованих каналів, категорії, пошук, обране, живий EPG-запит, назви «Зараз/Далі», час і прогрес-бар; прогрес оновлюється 30 с, EPG рефреш 10 хв. Офлайн тести — PASS, у тому числі реальний історичний EPG: TVP1 52%, TVP2 70%, TVN 20%, TVP Sport 22%.

**Це не реліз:** відтворення, запити з Lampa WebView і доступність сайту з приставок не перевірені; для 51 із 56 каналів URL у каталозі порожній. Старий LiveTV-плагін не чіпали. Реальний живий EPG у Lampa — ще не підтверджений.

Також підтверджено, що телеканал починає відтворюватися у внутрішньому/зовнішніх плеєрах **лише після відкриття саме цього каналу на сайті**. Офлайн-тест на збереженому HTML від 21 листопада: **188 DOM-подій, 29 LIVE, API O=2, 188 унікальних після злиття**, плюс 6 тестів Bridge. Ці показники **історичні**, не гарантують кількість поточних подій. Синхронізація Chrome залишається ручною. Працездатність на Android і відтворення прямих відеопотоків v0.14 ще не підтверджені.

## TV 0.14.2 — проба штатного маршруту (22.11.2026)

- Користувач підтвердив, що для перегляду каналу треба натиснути **рядок каналу в таблиці** на `/telewizja/`. Пряме відкриття `/telewizja/player.php?c=ID` показує польське **«Dostęp zabroniony — Kanał można oglądać tylko na stronie Strumyk»**.
- Діагностика TV v0.17 встановила: параметр `c` точно збігається з відкритим ID каналу (`canal-sport1`). В окремому GET-запиті `/api/tv.php` повернув **405**. Це НЕ доводить спосіб справжнього запиту, лише те, що наш пробний GET не підтримується.
- Опублікований **[test/strumyk_plugin_v0142_tv_site_route_test.js](test/strumyk_plugin_v0142_tv_site_route_test.js)** — *лише експериментальний тест*: при натисканні на TV-картку відкриває всередині Lampa сторінку `/telewizja/#ID`, щоб сайт сам створив свій iframe плеєра. Відтворення через нативні Lampa/VLC/MX поки не перевірене й не реалізоване.
- Важливо: якщо Strumyk блокує вбудовування цілого сайту за CSP/X-Frame-Options чи через власні перевірки контексту, цей тест теж не спрацює. Не намагатися підставляти фальшивий Referer або обходити обмеження сервера.
- Спортивний каталог 0.14 (**196 подій**) і Termux Bridge **не змінені**. Не називати 0.14.2 релізом.

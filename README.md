# STRUMYK SPORTS × Lampa

Дослідницький проєкт плагіна для **LampaS / Lampa Uncensored** під https://strumyk.ca/.

## Стан — v0.3.0 research (21.11.2026)

- Є локальний прототип JS-інтерфейсу, UA (за замовчуванням) / PL / RU, фільтри, обране і модель кількох джерел на подію.
- Файли з Termux довели: `https://strumyk.ca/` іноді повертає HTTP 200 із **проміжною сторінкою**, а не розкладом. У отриманому HTML 2824 байти, текст `Sprawdzamy połączenie…`, асинхронне завантаження JS із `cautiousfloor.com` і `location.reload()` через одну секунду.
- Призначення стороннього JS не встановлене; виконувати його у плагіні навмання не потрібно. Це не підтверджений стандартний Cloudflare Challenge; Cloudflare Insights — окрема аналітика.
- У v0.3 плагін розпізнає проміжну сторінку і показує окрему помилку. Локальні тести на справжньому зразку HTML пройдено.
- Створено локальний read-only браузерний засіб діагностики, який експортує очищену DOM-структуру та адреси ресурсів у JSON **без відправлення в мережу**. Наступний крок — отримати знімок нормального розкладу і відкритого матчу з Android Chrome.

**Живий API, реальна повнота списку джерел, VLC/MX Player, LampaS і Lampa Uncensored поки не перевірені.** Публікація невипробуваного JS як робочого релізу була б оманливою.

Це окремий проєкт, діючий LiveTV-плагін не змінюється. Ідентифікатори деяких посилань можуть міститися після `#`; їхню семантику ще потрібно перевірити.

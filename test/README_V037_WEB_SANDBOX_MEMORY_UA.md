# STRUMYK SPORTS v0.37 — пам'ять WEB sandbox за доменом

**Статус:** окрема експериментальна версія. **23.11.2026**.  
**База:** підтверджена WEB-версія `v0.35`, **НЕ** відхилена користувачем `v0.36`.  
**Протокол Lampa:** HTTP. Сайт Strumyk і плагін JS продовжують завантажуватися через HTTPS.

## Встановлення

```text
https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@fca39bb6cd44ed8c44e9c7f91d99290fc457df93/test/strumyk_plugin_v037_web_sandbox_memory_test.js
```

Вимкни v0.35 (і будь-яку іншу версію STRUMYK), повністю закрий Lampa, відкрий її знову та встанови лише v0.37. Один екземпляр плагіна за раз; у версій спільний прапорець ініціалізації.

## Навіщо зміна

Реальні тести користувача підтвердили:
- Nova Sport 5 FHD4 (`matchora.to`, джерело 4/9) відтворює відео **без sandbox**; із sandbox плеєр відмовляється.
- Arena Sport 2 HD (`wideiptv.top`, 5/9) показувала відео навіть **із sandbox**.
- Тому обидва режими потрібні. Версія v0.35 дозволяла перемикати їх, але не запам'ятовувала вибір для наступного відкриття.

## Що зроблено

1. При натисканні `🛡 Увімкнути sandbox` або `▶ Без sandbox (сумісність)` вибір записується **за hostname провайдера** у `Lampa.Storage` під ключем `strumyk_webSandboxByHost`.
2. При новому відкритті WEB цього домену встановлений користувачем режим автоматично відновлюється.
3. При перемиканні між `Попереднє/Наступне/Усі джерела` налаштування береться **для домену нового джерела**, а не успадковується помилково від попереднього.
4. **Повні URL, query-параметри, підписи, токени, cookies не зберігаються.** У сховищі лише домен і булеве значення `true/false`.
5. Для нових зовнішніх HTTPS-провайдерів за замовчуванням — режим **без sandbox** як у v0.35. HTTP-джерела та same-origin залишаються із sandbox.
6. Перемикач `sandbox` залишається доступним безпосередньо у WEB-плеєрі. При перемиканні iframe перезавантажується.

## Що НЕ змінювалось

**Точне порівняння коду:** усі частини v0.35 **поза `webPlayer()` і рядком `VERSION` побайтно однакові**. Це охоплює:
- `Lampa.Player.play`, `openStream`, XOR і пошук HLS/DASH;
- AutoStream v0.34, HLS `pLoader/fLoader`, нативний транспорт;
- спортивний каталог, EPG, LIVE, фільтри та Back;
- інший плагін LiveTV.

Жодні попередні `.js` не переписані.

## Тест на Android без ПК

1. **Спочатку перевір Lampa Player** на раніше перевіреному прямому потоці: рух, звук, роздільна здатність, буфер.
2. У WEB для **4/9** увімкни режим `без sandbox` і перевір відео. Вийди у картку події, відкрий 4/9 ще раз — режим має зберігатися.
3. Для **5/9** увімкни `sandbox`, потім повернися до 4/9 — має відновитися його власний режим.
4. Перезапусти Lampa, повтори 4/9 і 5/9 та перевір збереження налаштувань.
5. Переключай джерела `Попереднє/Наступне`, перевір Back та відсутність зеленої помилки.

**Ні робота на реальному Android, ні звук/рух у v0.37 ще не тестувалися користувачем.**

## Статичні перевірки

- JS parse / export version: **PASS**.
- Суворе порівняння поза WEB: **PASS**.
- **18** mock-тестів DOM і локального сховища: **PASS** (збереження, відновлення, ізоляція за доменами, нові адреси з токенами, перемикання, HTTP iframe, заборонені URL).

## Межі

Ця версія **не обіцяє зняти** `Access Denied / authorized domains`, бо для таких джерел провайдер застосовує власні серверні перевірки. Зміна `sandbox` або її запам'ятовування не змінює браузерний `Referer`/ `Origin`.

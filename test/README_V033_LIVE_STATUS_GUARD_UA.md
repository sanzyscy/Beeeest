# STRUMYK SPORTS v0.33 — виправлення помилкового «Наживо» (HTTP Lampa)

**Дата:** 22.11.2026  
**Статус:** окрема експериментальна версія, на реальному Android та Android TV ще не перевірена.  
**Встановлення:** https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@e21db7397921a939049ecd8b347b618e8c6f515f/test/strumyk_plugin_v033_live_status_guard_test.js

## Що показали скріншоти v0.32
- У картці `KSW 123`, датованій 21.11, 22.11 у меню «Наживо» ще залишались джерела.
- Вибране джерело 5/6 — `Nova Sport 1`, мова `Czeski`, `FHD` — показує кадр **хокею** у WEB iframe.
- Інший попередній скріншот того самого KSW 123 показував у iframe футбольний ефір `CANAL+ Extra 2`. Отже в картці доступні різні вебсторінки каналів, але **немає доказу**, що це трансляція KSW 123 у час тесту.
- `Прямий потік недоступний: HTTP 403` стосується спроби витягнути прямий HLS/DASH, **не є доказом відсутності WEB-відтворення**.
- Наявність кадру не доводить рух, звук, тривалість, правомірність доступу або правильну програму.

## Знайдена проблема
У `parseStrumykApiBundle` попередніх версій для записів джерел `J/O/X` без `endTime` була логіка:
```js
else { ev.live=true; ev.finished=false; ev.status='live'; }
```
Коли час початку вже минув, подія отримувала `live=true` **назавжди**, незалежно від того, скільки годин пройшло. Це логічна помилка, вона не залежить від роботи WEB iframe.

## Зміни в v0.33
1. Якщо `start` у майбутньому → `upcoming`. Якщо API надає **дійсний endTime**, час завершення враховується.
2. Якщо API явно підтвердив `finished`, статус не перезаписується оцінкою часу.
3. Якщо немає `endTime`, в `J/O/X` безпідставне `live=true` тепер обмежене **6 годинами після початку**. Для `L/M` зберігається попереднє вікно 150 хвилин.
4. Після закінчення такого вікна встановлюється `live=false, finished=false, status=stale_unverified`. Ми **не заявляємо, що матч завершено** — лише що факт live більше не підтверджений.
5. У вкладці «Наживо» діє додаткова перевірка актуальності для записів із HTML та об'єднаних API; тому старі події не повинні повертатися через дублікати.
6. Картки у розкладі мають чесніші позначки: `Ймовірно LIVE` / `Статус не підтверджено`. У картці старої події збережено всі доступні WEB-джерела та пояснення.
7. Не змінені **WEB iframe, перемикання попереднє/наступне/всі, плеєри, EPG, пошук медіаманіфестів і Back Controller** з v0.32.

Часове вікно — це консервативна евристика, не гарантована тривалість матчу. Довгі матчі/гонки без endTime можуть зникнути з вкладки «Наживо» після 6 годин, але залишаться у розкладі.

## Як тестувати
1. **Вимкнути v0.32**, перезапустити Lampa та встановити лише **v0.33** через pinned URL вище.
2. Запустити Lampa через **HTTP**. Сам Strumyk та JS з GitHub CDN можуть лишатися HTTPS.
3. Перейти у **«Наживо»** і перевірити, чи зникла `KSW 123` від 21.11. Вона має залишитися у загальному розкладі за умови, що API продовжує її повертати.
4. Перевірити кілька подій, що щойно почалися: вони можуть відображатися як **«Ймовірно LIVE»**, оскільки точний старт трансляції без фактичного плеєра не підтверджений.
5. Відкрити подію із WEB-джерелами, перевірити **попереднє/наступне/всі джерела**, кадри та Back.
6. Окремо перевірити EPG «Зараз / Далі» та список 56 каналів.
7. Написати, чи є **рух відео**, **звук**, **стабільна робота** після перемикання. Скріншот не може це підтвердити.

## Статична перевірка
- JS успішно розібраний у V8.
- **23 синтетичні перевірки PASS:** застарілі J/O/X, нові J/O, L/M, майбутні події, explicit endTime / finished, регресії HLS і WEB switcher.
- Реальний live status залежить від даних сайту та часу пристрою; перевірка на телефоні та ATV ще потрібна.

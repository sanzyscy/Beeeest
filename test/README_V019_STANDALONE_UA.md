# STRUMYK SPORTS v0.19 — автономний HTTP тест (22.11.2026)

## Ціль
Дізнатися, чи може **один JS-плагін у Lampa** отримувати спортивні події й телепрограму без Chrome bookmarklet, Termux Bridge, Python-сервісу чи іншого додатка.

Це **експеримент**, а не заміна перевіреного v0.14 (196 подій через DOM + Bridge). Не змінено `test/strumyk_plugin_v014_dom_test.js` та інші робочі файли.

## Встановлення
Вимкнути старий STRUMYK у розширеннях Lampa, повністю перезапустити програму та встановити лише:
`https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@c963df855c76ba4b7d4ff62daa8d1c5bfd88160d/test/strumyk_plugin_v019_standalone_http_test.js`

Плагін не звертається до `/catalog` Bridge чи `127.0.0.1:8754`. Відкриває `J/X/O`, а зі сторінок `/` та `/telewizja/` намагається знайти належні конфігураційні URL `L/M` і статичні `#schedList .sched-item`. Ключі й значення параметрів не вигадуються та не виводяться в діагностику.

## HTTP-профілі
Налаштування STRUMYK → «HTTP-заголовки для Strumyk»:

- **chrome** — Chrome-подібний User-Agent, який спрацював у тесті Termux v0.18, та Referer з доменом Strumyk (за замовчуванням).
- **chrome_ua** — той самий User-Agent, але без явно встановленого Referer.
- **webview** — User-Agent самої оболонки Lampa/WebView і Referer.
- **basic** — без явно встановлених User-Agent/Referer (інші базові заголовки залишаються).

Заголовки за замовчуванням додаються тільки на власний домен Strumyk. Інші медіадомени не отримують вигаданий Referer чи User-Agent.

## Тест
1. **Не відкривати Chrome**, не запускати Termux Bridge.
2. Увійти в STRUMYK → «Розклад», почекати завершення нативних HTTP-запитів.
3. Зафіксувати **скільки подій**, чи працюють фільтри, чи видно TV EPG.
4. Якщо каталог неповний — **Налаштування → HTTP-заголовки для Strumyk → Chrome UA БЕЗ Referer**, повторити.
5. Зробити скріншот **Діагностики**, де зазначено відповіді `J/X/O/L/M`, розмір HTML, кількість статичних DOM-подій. Не потрібні окремі JSON-файли.

## Обмеження
- Повний список 196 подій **ще НЕ доведений** без браузерного DOM. Якщо сайт створює більшість рядків лише після виконання власного JavaScript, звичайний HTML-запит їх не побачить.
- Сервер може вимагати тимчасові підписані параметри `t/s/ip` для L/M; UA не створює ці параметри.
- Телевізійні канали: EPG запитується без Bridge, але **автономний HLS у Lampa/VLC/MX не підтверджено**. Канали без прямого дозволеного URL відкриваються на офіційному сайті, не в нативному плеєрі.
- У деяких Android-оболонках Lampa заголовок Referer може змінюватися нативним мережевим мостом. На webOS/Tizen/вебверсії можливості нативного мережевого клієнта інші.

## Критерій успіху
Без Chrome/Termux отримати повний, свіжий спортивний каталог із правильними деталями, повний доступний список джерел для вибраної події, EPG і запуск тих медіапотоків, які постачальник дозволяє для зовнішнього відтворення. Повний успіх поки **не заявляти**.

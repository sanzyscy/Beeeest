# STRUMYK SPORTS v0.20 — автономний тест медіаджерел

Стан: **тестова версія**, НЕ реліз перевіреного відтворення. Основа — перевірена на Android v0.19: 189 спортивних подій, 56 телеканалів і автономна EPG. Початкова v0.14 з Termux Bridge та v0.19 не змінюються.

## Принцип
Для спортивних подій Strumyk використовує групи `_embeds` (мова/канал/якість). У публічному JS сайту ці адреси передаються у веб-`iframe` і не обов'язково є HLS.

У v0.20 додано **дійсну перевірку джерела перед передачею плеєру**:
1. На картках матчів із джерелами показується `🎬 Джерела: N`.
2. На сторінці матчу є `▶ Автоматично знайти HLS/DASH` — перевіряє до **4 унікальних** джерел, прямі — першими.
3. За потреби читає відкриту HTML-сторінку джерела й **не глибше одного вкладеного iframe** через HTTP-клієнт Lampa. Без `eval`, обходу DRM чи використання кукі браузера.
4. За знайденою `.m3u8` / `.mpd` адресою перевіряє вміст маніфесту (для HLS — `#EXTM3U`, для DASH — `<MPD>`).
5. **Лише якщо маніфест реально повернувся**, пропонує запуск у Lampa Player або VLC/MX Player із HTTP-заголовками профілю. Це *не* гарантує, що сегменти будуть доступні чи відео фактично відтвориться.
6. Якщо немає верифікованого маніфесту, показує причину та **не** передає HTML-посилання до VLC.

Сайт, токени і повні URL медіапотоків не записуються у звіти. Діагностичні помилки очищаються від URL.

## Установка та перевірка
1. Вимкнути попередню v0.19 (або v0.14), перезапустити Lampa і встановити **лише** цей JS:
   `https://cdn.jsdelivr.net/gh/sanzyscy/Beeeest@75a9108706a8dc40333195fb691bb62e31fd56a9/test/strumyk_plugin_v020_video_source_test.js`
2. Termux, Chrome, Bridge не потрібні.
3. Перейти **«Розклад» або «Наживо»**. Вибрати матч, де є `🎬 Джерела: N` (не порожнє).
4. У картці матчу натиснути `▶ Автоматично знайти HLS/DASH`.
5. Якщо знайдено маніфест — натиснути `▶ Lampa Player`, перевірити *фактичне* відео/аудіо. За потреби — VLC/MX.
6. Якщо невдача — надіслати скріншот **картки події та повідомлення**, не копіюючи токени.
7. «Діагностика» тепер показує `Events with sources` і `Direct media refs` — це окремий показник від загальної кількості подій.

## Телебачення: поточне обмеження
- EPG 56/56 — працює.
- У зафіксованій базі 51/56 телеканалів не мають доступного прямого URL; у чотирьох є відкриті WEB-сторінки і один має URL з прихованими параметрами. Ці сторінки **не прирівнюються** до HLS.
- `player.php?c=ID` напряму повертав `Dostęp zabroniony` («Лише на Strumyk»); GET на `/api/tv.php` → 405. Немає підтвердженої легітимної схеми видачі окремих HLS для нативного Lampa Player.
- TV-плеєр наразі **не виправлений**. Для каналів із WEB URL можна вибрати існуючий пошук HLS в меню джерела, але відтворення не гарантоване; інші відкриваються на сайті.
- Не вигадувати значення `c`, підписи, кукі або незареєстровані медіо-URL.

## Перевірки до публікації
- JavaScript-синтаксис: PASS.
- Ядро: JSON з `_embeds` → два джерела `web`, `hls`: PASS із тестовим URL shim.
- Пошук HLS у HTML і на одному рівні вкладеного iframe: PASS на штучних HTML-сторінках.
- Відсутність викликів Termux Bridge: PASS.
- РЕАЛЬНИЙ запуск відео на Lampa: **не перевірений**.
